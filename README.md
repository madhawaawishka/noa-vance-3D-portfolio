# Noa Vance — Portfolio

An animated portfolio site for a brand & web designer, featuring a 3D character hero, scrolling marquees, and motion-driven sections.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** — build tooling & dev server
- **Tailwind CSS** — styling
- **Framer Motion** — animations
- **lucide-react** — icons

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

## Project Structure

```
src/
  components/   Reusable UI (AnimatedText, Magnet, FadeIn, buttons)
  sections/     Page sections (Hero, About, Services, Projects, Marquee)
  App.tsx       Root layout
  main.tsx      Entry point
public/
  assets/       SVG decor, marquee, project artwork
```
